# Information Contradiction Finder

## About the Project
Information Contradiction Finder is a web-based application that we are developing to identify conflicting information from different sources.
Sometimes different websites provide different information about the same topic. Our application aims to help users compare two statements and identify possible contradictions using Natural Language Processing (NLP).

## Objectives
- To create a simple and user-friendly website.
- To compare information from two different sources.
- To identify contradictions using NLP techniques.
- To display the comparison results clearly.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- Natural Language Processing (NLP)

## Features
- Homepage with a simple interface
- Two text boxes for entering statements
- Check Contradiction button
- NLP-based contradiction detection (planned)
- Result display with confidence score (planned)

## Project Status
The project is currently under development. We have started with the frontend using HTML, CSS and JavaScript. The backend and NLP model will be added in the next stages.

## Future Improvements
- Allow users to compare information using website URLs.
- Highlight contradictory statements.
- Improve the accuracy of contradiction detection.
